# 共享单车调度系统 · 本地启动指南

## 一、打开终端，切换到项目目录

```powershell
E:
cd "E:\Sharing bike\FleetPy-main\FleetPy-main"
```

## 二、激活虚拟环境

```powershell
conda activate fleetpy
```

## 三、启动服务

```powershell
python app.py
```

看到以下输出说明启动成功：

```
* Running on http://127.0.0.1:8000
```

## 四、打开浏览器访问

```
http://127.0.0.1:8000
```

## 功能说明

| 菜单项 | 说明 |
|--------|------|
| 模拟可视化 | 查看无人车收集单车的动态演示，点击「播放」开始 |
| 数据分析 | 忙碌趋势、剩余单车趋势、行驶距离、KPI汇总 |
| 配置 | 当前仿真参数与算法策略说明 |
| 运行时间线 | 自动提取的出发/捡车/返站事件列表 |
| 空间热力图 | 单车散落热点分布图 |
| 运营看板 | 调度次数、取车距离、各站收车量、时段分布 |
| 重新模拟 | 单车重新分布，切换下一套预设方案（共3套循环） |
| 退出登录 | 退出当前账号，返回登录页 |

---

## 注意事项

- 服务运行期间**不要关闭终端窗口**
- 按 `Ctrl + C` 可停止服务
- 切换预设后浏览器会**自动刷新**，无需手动操作
- 所有功能页面数据**随重新模拟自动联动更新**
