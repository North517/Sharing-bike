# 共享单车调度系统 · 本地启动指南

## 一、打开终端，切换到项目目录

```powershell
E:
cd "E:\Sharing bike\FleetPy-main\FleetPy-main"
```

## 二、激活虚拟环境

```powershell
conda activate fleetpy
```

## 三、启动服务

```powershell
python app.py
```

看到以下输出说明启动成功：

```
* Running on http://127.0.0.1:8000
```

## 四、打开浏览器访问

```
http://127.0.0.1:8000
```

## 功能说明

| 菜单项 | 说明 |
|--------|------|
| 模拟可视化 | 查看无人车收集单车的动态演示，点击「播放」开始 |
| 空间热力图 | 单车散落热点分布图（高德地图底图） |
| 运营看板 | 调度次数、取车距离、各站收车量、时段分布 |
| 数据分析 | 忙碌趋势、剩余单车趋势、行驶距离、KPI汇总 |
| 运行时间线 | 自动提取的出发/捡车/返站事件列表 |
| 系统配置 | 当前仿真参数与算法策略说明 |
| 用户管理 | 仅管理员可见，可新建/删除用户、重置密码、查看登录日志 |
| 重新模拟 | 单车重新随机分布，所有页面数据自动联动更新 |
| 退出登录 | 退出当前账号，返回登录页 |

## 数据库查看（Navicat）

系统使用 **SQLite** 数据库管理用户信息，数据库文件路径：

```
E:\Sharing bike\FleetPy-main\FleetPy-main\users.db
```

**Navicat 连接步骤：**
1. 新建连接 → 选择 **SQLite**
2. 数据库文件选择上方路径
3. 连接成功后可查看：
   - `users` 表：用户名、加密密码、角色、创建时间、最近登录
   - `login_log` 表：每次登录的用户、时间、IP记录

> 演示技巧：在网页用户管理界面新建/删除用户后，在 Navicat 中刷新表格，可实时看到数据库记录变化。

---

## 注意事项

- 服务运行期间**不要关闭终端窗口**
- 按 `Ctrl + C` 可停止服务
- 点击「重新模拟」后浏览器会**自动刷新**，无需手动操作
- 所有功能页面数据**随重新模拟自动联动更新**
- 用户管理功能需使用 **admin** 账号登录才可见
